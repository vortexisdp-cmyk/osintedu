BUG-024 🟡 Мажорная NEW Локализация / Интерфейс

Языковой переключатель RU · EN · PT — мёртвый элемент: переводы EN и PT-BR отсутствуют

Что не так

В шапке отрисован переключатель языков RU / EN / PT (причём задвоенный — см. BUG-008: в снапшоте читается «RUENPTRUENPT»). Однако контент на английском и бразильском португальском в проекте не существует: клик по EN или PT ничего не меняет, интерфейс остаётся полностью русским. Видимый элемент управления, который ничего не делает, — обман пользователя и прямое нарушение WCAG 3.2.2 (предсказуемость поведения).

Либо подключаются переводы (готовый механизм и словарь — ниже), либо кнопки EN/PT удаляются до появления контента. Оставлять их нельзя.

Локация

.lang-switch button[data-lang="en"] .lang-switch button[data-lang="pt-BR"] весь контент страницы — только ru
Фикс · HTML + JS
<!-- разметка: переводимые узлы помечаем data-i18n -->
<div class="lang-switch" role="group" aria-label="Язык интерфейса">
  <button type="button" data-lang="ru"    aria-pressed="true">RU</button>
  <button type="button" data-lang="en"    aria-pressed="false">EN</button>
  <button type="button" data-lang="pt-BR" aria-pressed="false">PT</button>
</div>

<a href="#home" data-i18n="nav.home">Главная</a>
<span data-i18n="hero.kicker">Руководство 2025–2026</span>

// JS — полный словарь см. в разделе «Словарь переводов»
const I18N = {
  ru:      { 'nav.home': 'Главная', /* … */ },
  en:      { 'nav.home': 'Home',    /* … */ },
  'pt-BR': { 'nav.home': 'Início',  /* … */ }
};

function applyLang(lang) {
  if (!I18N[lang]) lang = 'ru';              // fallback → базовый язык
  document.documentElement.lang = lang;      // <html lang="en"> и т. д.
  document.querySelectorAll('[data-i18n]').forEach(function (node) {
    const key = node.getAttribute('data-i18n');
    node.textContent = (I18N[lang] && I18N[lang][key]) || node.textContent;
  });
  document.querySelectorAll('.lang-switch button').forEach(function (btn) {
    const on = btn.dataset.lang === lang;
    btn.classList.toggle('is-active', on);
    btn.setAttribute('aria-pressed', on ? 'true' : 'false');
  });
  try { localStorage.setItem('lang', lang); } catch (e) {}
}

document.querySelectorAll('.lang-switch button').forEach(function (btn) {
  btn.addEventListener('click', function () { applyLang(btn.dataset.lang); });
});

// инициализация: ?lang=… → сохранённый → язык браузера → ru
const langs = Object.keys(I18N);
const param = new URLSearchParams(location.search).get('lang');
let saved = null;
try { saved = localStorage.getItem('lang'); } catch (e) {}
const browser = langs.find(function (l) {
  return l.toLowerCase() === (navigator.language || '').toLowerCase();
});
applyLang(param || saved || browser || 'ru');
Фикс · CSS (состояния + тач-цели)
.lang-switch { display: flex; gap: 6px; }
.lang-switch button {
  min-height: 44px;                 /* см. BUG-003 — тач-цели */
  min-width: 44px;
  border: 1px solid var(--line);
  border-radius: 8px;
  font-weight: 700;
  transition: background .2s, color .2s, border-color .2s;
}
.lang-switch button.is-active {     /* активный язык всегда виден */
  background: #14181f;
  color: #fff;
  border-color: #14181f;
}
BUG-025 🟢 Минорная NEW Доступность / SEO

Выбор языка не фиксируется: нет aria-pressed, persistence и hreflang

Что не так

Даже если бы переводы появились, у переключателя нет активного состояния (непонятно, какой язык выбран), нет aria-pressed, выбор не сохраняется между визитами, а атрибут <html lang> не обновляется — скринридеры продолжат читать бразильский текст русской фонетикой. Поисковикам не указан hreflang.

Локация

<head> — нет hreflang <html lang="ru"> — не обновляется состояние кнопок переключателя
Фикс · HTML (hreflang)
<link rel="alternate" hreflang="ru"        href="https://…/index.html">
<link rel="alternate" hreflang="en"        href="https://…/index.html?lang=en">
<link rel="alternate" hreflang="pt-BR"     href="https://…/index.html?lang=pt-BR">
<link rel="alternate" hreflang="x-default" href="https://…/index.html">

/* aria-pressed, localStorage и обновление <html lang>
   уже покрыты скриптом applyLang() из BUG-024 */

Словарь переводов — готов к вставке

20 ключей × 3 языка Каркас интерфейса: навигация, герой, чипы, UI

Покрывает весь повторяющийся каркас страницы. Остальные ~120 строк (заголовки разделов, карточки, советы) переводятся по той же схеме data-i18n.

Ключ 🇷🇺 RU · базовый 🇬🇧 EN 🇧🇷 PT-BR

Примечание: «бразильский» в переключателе — это pt-BR (португальский бразильский вариант). Код языка в разметке и hreflang должен быть именно pt-BR, а не pt, иначе бразильские пользователи будут получать европейский португальский из Португалии.
